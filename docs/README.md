# TIA Website — Documentation

This folder contains documentation for developers working on the TIA (Technical Investment Association) website.

| Document | Purpose |
|----------|---------|
| [**SETUP.md**](./SETUP.md) | Environment, Firebase, running locally, **Firestore/Storage rules and indexes**, build and deploy |
| [**ARCHITECTURE.md**](./ARCHITECTURE.md) | Codebase structure, routing, auth, design system, performance |
| [**HANDOVER.md**](./HANDOVER.md) | Onboarding, where things live, common tasks, handover checklist |

Start with **SETUP.md** to get the site running, then **ARCHITECTURE.md** for how the project is organised. Use **HANDOVER.md** when onboarding someone new or preparing a handover.
